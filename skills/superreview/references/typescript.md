# TypeScript and JavaScript

Trace unawaited promises, rejection handling, cancellation, and bounded concurrency.
`void` does not itself handle rejection. Check runtime input validation independently of
compile-time types, stale closures, effect cleanup, precision, nullish versus falsy values,
and serialization across clients. Verify runtime versions before declaring an API unsupported.
For transaction concurrency, inspect the driver's semantics rather than imposing a universal
ban. For UI changes check keyboard access, loading/error states, and races across requests.
